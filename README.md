# sakkarinkt.github.io

Personal site of Sakkarin Krarat, AI/ML engineer in Taipei. Live at **https://sakkarinkt.github.io/**.

Next.js 16 (App Router, static export) · React 19 · TypeScript · Tailwind CSS v4 · Motion · MDX · cmdk.

## What's interesting in here

- **fig. 1, a live RL demo.** Tabular Q-learning on a 12×8 gridworld, running in the browser. Visitors can draw walls or move the goal, and the agent re-learns. The core is pure, seeded TypeScript (`lib/rl/`) with unit tests. The server renders the converged policy as SVG at build time, so there's no layout shift, and reduced-motion visitors get a static figure.
- **Honesty is enforced by the schema.** Case studies are MDX with zod-validated frontmatter (`lib/content/schema.ts`). Every metric needs an `n`. Every case study needs `honestLimits`. Non-public work can't link a repo. The build fails if any rule is broken.
- **⌘K command palette.** cmdk plus a Radix Dialog, lazy-loaded and prefetched when the browser is idle.
- **Architecture diagrams are data.** `components/diagram/specs.ts` renders them to theme-aware inline SVG on the server, with no client JS.
- **Build gates.** `prebuild` validates content and renders OG cards (satori + resvg). `postbuild` checks the export: every internal link and `#anchor` resolves, OG images are real PNGs, and no `TODO(owner)` placeholder ships.

## Commands

| Command | Does |
| --- | --- |
| `npm run dev` | Dev server on :3000 |
| `npm run build` | Validate content → OG cards → `next build` → verify `out/` |
| `npm run preview` | Serve `out/` on :4173 |
| `npm test` | Vitest (RL core, content rules, legacy redirects) |
| `npm run typecheck` / `npm run lint` | `next typegen && tsc`, ESLint |

Local builds with placeholder copy still in place: `ALLOW_TODO=1 npx tsx scripts/verify-export.ts`.

## Content

- `content/projects/*.mdx`: case studies (public repos only). Required H2s: Problem, Approach, Architecture, Results, What’s next.
- `content/posts/*.md`: writing. `legacySlugs` keeps old Astro URLs redirecting.
- `content/data/*.ts`: profile, now, experience, education, skills, values, lab bench, planned work.
- `public/resume.pdf`: optional. The résumé button and palette entry appear only if this file exists.

## Deploy

GitHub Actions (`.github/workflows/deploy.yml`) builds on every push and PR, and deploys `out/` to Pages from `main`. In repo settings, set **Settings → Pages → Source** to *GitHub Actions*.
